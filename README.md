# Kirby.LuaScript
Luascript in Kirby's theme
<p>Test on Radiomaster Boxer and Pocket Radio </p>
<u><b>Install:</b></u>
<p>Plug your remote control into your PC</p>
<p>Select "SD card"</p>
<p>Go to SD:/SCRIPTS/TELEMETRY/</p>
<p>past kirby.lua</p>
<p>Unplug your remote control</p>
<p>Push the button  MDL </p>
<p>Go to menu DISPLAY </p>
<p>Edit Screen 1 > type "Script" > kirby</p>
<p>Push "TELEMETRY" button</p>

<p>Enjoy :)</p>
